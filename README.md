# Vue 3 + Vite + TypeScript + Sass

This project uses Vue 3 with Vite, TypeScript, and Sass. Vue components use `<script setup lang="ts">`, and global styles live in `src/style.scss`.

Learn more about IDE Support for Vue in the [Vue Docs Scaling up Guide](https://vuejs.org/guide/scaling-up/tooling.html#ide-support).

## 使用 Bun

本项目使用 [Bun](https://bun.com/) 管理依赖并运行脚本。请先安装 Bun，然后执行：

```bash
bun install
```

常用命令：

```bash
bun run dev        # 启动开发服务器
bun run build      # 构建生产版本
bun run preview    # 预览生产构建
bun run type-check # 执行 TypeScript/Vue 类型检查
```
